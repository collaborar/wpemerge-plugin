# WP Emerge

## Structure

The current directory is a WordPress plugin and the following ones is packages for WP Emerge framework.

`packages/wpemerge` -- Micro-framework for WordPress development
`packages/wpemerge-cli` -- CLI commands for wpemerge it runs through root `wpemerge` file
`packages/wpemerge-app-core` -- WordPress utilities to development
